## Description

Laboratories in the course CAr - Computer Architecture at HEI Valais-Wallis.

## How to use

Simply clone or download the repository.

### Windows

  ```bash
  mkdir -p c:/work
  cd /d c:/work
  git clone https://github.com/hei-isc-car/car-labs.git
  cd car-labs
  ```

### Linux & Mac

  ```bash
  # clone repo
  mkdir -p ~/work
  cd ~/work
  git clone https://github.com/hei-isc-car/car-labs.git
  cd car-labs
  ```
