# Multiplication by Repeated Addition

## Tasks

1. Implement multiplication n * n with an addition loop.
2. Test with `n = 5, 10, 20, 0`
3. Generalize multiplication i * j with an addition loop.
4. Test with `i = 5, j = 20` and `j = 5, i = 20`. How does the runtime changes (check cycles count) ?
5. Test with `i = 500, j = 100` and `j = 100, i = 500`. How does the runtime changes (check cycles count) ?
