# Do-While Countdown

## Tasks

1. Initialize counter variable.
2. Execute decrement in loop body.
3. Repeat while counter is not zero.
4. Keep operations aligned with C snippet intent:
```c
  int a = 10;
  do{a = a - 1;}
  while(a != 0);
```
