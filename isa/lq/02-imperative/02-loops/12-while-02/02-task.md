# While Countdown

## Tasks

1. Initialize counter variable.
2. Test loop condition before body execution.
3. Decrement in body and branch back to test.
4. Stop when condition fails.
5. Keep operations aligned with C snippet intent:
```c
  int a = 10;
  while(a >= 0)
    {a = a - 1;}
```
